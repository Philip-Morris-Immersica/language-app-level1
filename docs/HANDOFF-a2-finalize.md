## Дневник

### Фаза 0 — inventory + план · 2026-09-03, planning чат

Одит какво добави финализиращият pass на A1 и какво липсва на A2. Резултатът е
в „Факти“ в плана. Ключовите находки: pretranslate кешът има **0** A2 записа,
A2 има **0** `sectionStart` (A1 има 56 в 11 урока), нито един A2 урок не е в
`CELEBRATION_ENABLED_LESSONS`. `grammarReference` и `instructionKey` в A2 са
**готови** — A2 дори е пред A1 по `instructionKey` (75 срещу 54).

Документът първоначално беше един файл, който смесваше план и дневник (по
образеца на `HANDOFF-alex-merge.md`). Разделен на два по искане на Philip:
планът е статичен и се чете, дневникът расте и се пише. Причина: агент за Фаза 4
трябва да прочете ~80 реда, не 505.

### Фаза 1 — локален мърдж на A2 · 2026-09-03, planning чат

```
git checkout master && git pull            # e5564c8
git checkout -b a2-merge origin/nina       # ccb3173
git merge master --no-edit                 # exit 0, НУЛА конфликта
npm run content:lint                       # 0 errors, 32 warnings
npm run build                              # exit 0, 542s, 53 страници
git push origin a2-merge                   # нов клон, dc8216f
gh pr create --base master --head a2-merge # PR #15
```

Шест детерминистични проверки, всички чисти — таблицата е в „Факти → Мърджът е
чист“ в плана. `master` е **непокътнат** (`e5564c8`), PR #15 е `mergedAt: null`.

**Отклонение от очакването:** мърджът на Алекс беше труден заради
`scripts/generate-tts.ts`, който git auto-merge-на в хибрид. Тук такъв риск
нямаше — пресечното множество между файловете на Нина и файловете на master е
празно. Затова нула конфликта не е изненада, а следствие.

**Капан, който хванах:** `git checkout -b a2-merge origin/nina` слага
`origin/nina` като upstream — един разсеян `git push` без аргументи би стрелял
по чужд клон. Пренасочено веднага след push-а:
`git branch --set-upstream-to=origin/a2-merge a2-merge`. Проверено, че
`origin/nina` е непроменен (`ccb3173`).

**Какво остава на Philip преди мърджа:** стъпка 6 от
[philip-team-lead](../.cursor/rules/philip-team-lead.mdc) — локална браузър
проверка. Командите са във „Фаза 1“ в плана.
