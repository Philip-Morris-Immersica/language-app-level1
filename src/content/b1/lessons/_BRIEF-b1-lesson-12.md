## `b1-select-words` — точното съдържание (стр. 84, 6 изречения)

Това е **мулти-избор**: в едно изречение има по 2–3 верни думи. Оценява се по
изречение — уцелваш точката само при точно съвпадение с верния набор, така че
маркирането на всичко не дава точки.

Форма на данните (`sentences[]`): `before` = текстът преди чиповете, `words[]` =
кандидат-думите в реда от учебника (компонентът **не** разбърква — учебниковият
ред вече е смесен), `after` = затварящата пунктуация.

| # | кандидат-думи (в реда от учебника) | верни |
|---|---|---|
| 1 | хуни, траки, готи, келти, скити, славяни, прабългари | 3 |
| 2 | черна, кестенява, червена, светла | 3 |
| 3 | Аспарух, Кубрат, Спартак, Орфей | 2 |
| 4 | земеделие, животновъдство, търговия, металообработване, занаятчийство | 3 |
| 5 | реки, езера, блата, планини | 3 |
| 6 | славяните, иранците, хуните | 2 |

Кои точно са верните се сверява с текста на стр. 83–84 в `_b1-source/lesson-12.md`.
`points: 6` = брой изречения (правилото „points = брой въпроси", не брой думи).

Пример за структурата:

```ts
{
  id: 'b1-l12-ex-07',
  type: 'b1-select-words',
  title: 'УПРАЖНЕНИЕ 7',
  instruction: 'Прочетете текста и натиснете всички думи, които са верни според него.',
  instructionKey: 'b1.exercise.selectAllCorrectWords',
  order: 9,
  points: 6,
  sentences: [
    {
      id: 'а.',
      before: 'По българските земи са живели',
      after: '.',
      words: [
        { text: 'хуни' },
        { text: 'траки', correct: true },
        // …
      ],
    },
  ],
} as unknown as MultipleChoiceExercise,
```

Кастът `as unknown as <най-близкия shared тип>` е установената B1 конвенция за
`b1-`  типовете (виж `b1-lesson-10/exercises.ts`) — нужен е само за да влезе
обектът в `Exercise[]`.

## Решения от въпросника, които важат тук

- **B2 — мулти-избор:** нов компонент `b1-select-words` (опция а), не 6 × `b1-sort-to-columns`.
  Причина: `multiple_choice` има точно един верен отговор, `workbook_fill_blank`
  е dropdown — също един избор.
- **C2.4 — въпрос 7 към „Заветът на хан Кубрат":** отговорът („Съединението прави
  силата") **не е в текста**. Решение: добавя се едно изречение в културната
  бележка, което дава връзката, и въпросът остава оценен (`points: 7`).
- **D — граматика:** сложни думи, съкращения (г., в., пр.н.е.) и напомняне за
  преизказно наклонение. Пълният справочник за преизказното е в **урок 11** (реш. D1).
- **A2 — НОВИ ДУМИ:** правим ги сами, `imageUrl: ''`.

## Граматика (`grammarReference` в `content.ts`, 7 езика, ръчно)

1. `b1-l12-gr-slozhni-dumi` — сложни думи: как две основи се свързват с
   съединителна гласна (*животно + въдство → животновъдство*,
   *метал + обработване → металообработване*).
2. `b1-l12-gr-sakrashteniya` — съкращения: `г.` = година, `в.` = век,
   `пр.н.е.` / `сл.н.е.`, `т.нар.` Включи как се четат на глас — това е и TTS
   въпрос: в `ttsText` се изписват разгърнато („втори век преди новата ера").
3. `b1-l12-gr-preizkazno-razshirenie` — преизказно наклонение, разширение.
   Пълният справочник е в урок 11; тук се добавя само употребата в трета легенда.
