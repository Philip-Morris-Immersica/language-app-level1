# B2 lessons

Each digital lesson lives in `b2-lesson-NN/` with:

- `metadata.ts`
- `content.ts`
- `exercises.ts`
- `workbook.ts`
- `index.ts`

Approved plans are stored beside the lesson folders as
`_PLAN-b2-lesson-NN.md`.

Follow `.cursor/rules/alex-b1-b2.mdc` and use `/b2-plan` before creating a
lesson folder.
